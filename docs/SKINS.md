# Profile skins — scouting results

A survey of the repos that render "skins" for a GitHub profile README, filtered for
what would actually suit **this** profile. Every preview below is live: it is rendering
right now, for `YAMANOE`, in this file. Scroll and pick.

This is a scouting document, not part of the profile. Nothing here is wired into
`README.md` until you say which ones you want.

> Star counts recorded 2026-08-23.

---

## The one thing to decide first

This repo already made a decision about skins. Commit `9d6bd60` —
*"Replace rented header services with a self-hosted animated hero"* — moved the header
off a third-party render service and into `assets/hero.svg`, committed here.

That decision splits the entire field in two, so it is the axis this document is
organised by:

| | **Self-hosted** | **Rented** |
|---|---|---|
| How it works | A GitHub Action runs on a schedule, generates an SVG, commits it into this repo | The README hotlinks a URL; someone else's server renders on every page view |
| Already used here | `Platane/snk`, `yoshi389111/github-profile-3d-contrib` | `img.shields.io` (the contact row) |
| Fails when | Never — the SVG is a file in the repo | Their server is down, rate-limited, cold-starting, or shut down |
| Cost | A workflow file and a commit per day | Nothing, until it breaks |

**Worth knowing:** the contact badges at the bottom of the README are already
`img.shields.io` hotlinks, so the "no rented services" rule has one live exception.
Whether that exception widens is the actual choice in front of you.

# Part 1 — Self-hosted (Action commits the SVG here)

These match the standard the profile already set. Recommended.

### 1. lowlighter/metrics — ★17,093
[`lowlighter/metrics`](https://github.com/lowlighter/metrics) · 30+ plugins, 300+ options

The most capable thing in this entire field, and it runs as an Action that commits SVG
into your repo. Plugins for languages, activity, achievements, isocalendar, habits,
and a lot more. If you adopt exactly one new skin, this is the one — it is the only
option here whose output you can tune to the profile's palette *and* fully own.

<img alt="metrics preview" src="https://raw.githubusercontent.com/lowlighter/metrics/examples/metrics.plugin.isocalendar.fullyear.svg" width="70%" />

```yaml
# .github/workflows/metrics.yml
name: Metrics
on:
  schedule: [{ cron: "0 3 * * *" }]
  workflow_dispatch:
jobs:
  build:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: lowlighter/metrics@latest
        with:
          token: ${{ secrets.METRICS_TOKEN }}   # a classic PAT, scope: read:user
          filename: assets/metrics.svg
          base: header, activity, community, repositories, metadata
          config_timezone: Asia/Amman
          plugin_languages: yes
          plugin_languages_details: percentage
          plugin_languages_limit: 6
```

```markdown
<img alt="metrics" src="./assets/metrics.svg" width="100%" />
```

> Needs a personal access token (`METRICS_TOKEN`), unlike the two Actions already here.

### 2. vn7n24fzkq/github-profile-summary-cards — ★3,625
[`vn7n24fzkq/github-profile-summary-cards`](https://github.com/vn7n24fzkq/github-profile-summary-cards) · Action, commits SVG

Five cards — profile details, languages by repo, languages by commit, stats, commit
hours. Runs as an Action and commits into `profile-summary-card-output/`, exactly the
pattern `profile-3d-contrib/` already uses here.

<img alt="summary card preview" src="https://raw.githubusercontent.com/vn7n24fzkq/github-profile-summary-cards/master/preview/1.svg" width="70%" />

```yaml
# .github/workflows/summary-cards.yml
name: Profile summary cards
on:
  schedule: [{ cron: "0 4 * * *" }]
  workflow_dispatch:
jobs:
  build:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v5
      - uses: vn7n24fzkq/github-profile-summary-cards@release
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        with:
          USERNAME: ${{ github.repository_owner }}
          UTC_OFFSET: 3
```

## Recommendation

The current README is unusually restrained for a profile README: it leads with problem,
approach, scale and guarantee rather than with widgets, and its one caption about
contributions explicitly de-emphasises them. Most of this catalog would work against
that, so the shortlist is short:

**Worth adding**
1. **`lowlighter/metrics`** (Part 1) — self-hosted, matches the standard `9d6bd60` set, and is the only option that can be tuned to the palette while staying a file in this repo.
2. **`github-readme-activity-graph`** (Part 2) — if you want one hotlinked card. A plain line chart is the only rented skin whose visual language matches the rest of the page.

**Worth skipping** — trophies, typing SVG, capsule-render and skill-icons each
duplicate or contradict something the README already does better, for the reasons noted
under each.

**Open question for you:** does the profile stay self-hosted-only (Part 1, plus the
shields.io exception already in the contact row), or does it accept hotlinked cards?
Everything else follows from that.
