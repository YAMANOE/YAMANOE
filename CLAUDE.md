## README is a live public page

`README.md` renders on the public profile at <https://github.com/YAMANOE>.
A mistake here is visible to everyone immediately, so:

- Never reference an image that does not exist yet. Generate the file, confirm
  it is committed, and only then add the `<img>` tag. Referencing first shows a
  broken image on the profile until the file lands.
- Never ship a change that depends on a secret or setting that has not been
  created yet.
- Every image the README points at must resolve before pushing.

## Workflows

- `snake.yml` and `profile-3d.yml` render contribution graphs with the built-in
  `GITHUB_TOKEN`.
- `metrics.yml` is dormant. It needs a `METRICS_TOKEN` secret (a scopeless
  classic PAT) and skips cleanly, finishing green, while that is absent.
- `GITHUB_TOKEN` is scoped to this repository alone. It cannot read across the
  account, so any card aggregating languages, repositories or activity needs a
  personal access token. Contribution-calendar data is the one exception.
