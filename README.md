### About
I build bilingual AI systems for the public sector in Jordan, working across Arabic NLP, computer vision, and geospatial intelligence.

### Selected projects
- **[RegTech](https://github.com/YAMANOE/rag-tech):** search legislation and articles, trace legal history and relationships, compare available versions, and distinguish verified, inferred, generated, and unavailable information.
- **Traffic Intelligence:** bilingual routing and corridor analysis with evidence checks. Illustrations in this profile are conceptual.
- **[NextGen Recommender](https://github.com/YAMANOE/recom_sys):** hybrid retrieval, recommendation explanations, feedback memory, and saved sessions.
- **[Toxic Text Classification](https://github.com/YAMANOE/nlp_pro1):** bidirectional LSTM and LoRA-tuned DistilBERT, with project evaluation results.

### Technologies
Python, TypeScript, React, Next.js, FastAPI, NestJS, Docker, PostgreSQL, Supabase, Ollama, Hugging Face, PyTorch, TensorFlow, OpenCV, scikit-learn, OpenStreetMap, PostGIS, and pgRouting.
